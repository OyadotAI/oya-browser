Owned all the way down

Oya handles HTTP framing, document parsing, block flow, text wrapping, event execution and agent operations. macOS supplies the window, controls, fonts and drawing.

Mars is Oya’s Rust browser for people and agents. Eye owns documents and rendering, V9 runs JavaScript, and Relay handles networking. These engines are under active development toward replacing Oya’s Electron browser.
